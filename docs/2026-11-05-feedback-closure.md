## 二、四条根因值得单独记

这四条的共同形状：**代码看着是对的，运行起来也是"对的"，但依据是空的或错的。**

### ① 公差枚举整表错位（#6）

```python
{"basic": 1, "bilateral": 2, "limit": 3, "symmetric": 4}
```

`swTolType_e` 的真实顺序是 `BILAT=1, LIMIT=2, SYMMETRIC=3, MIN=4`。

**所以"bilateral"一直在要求 SolidWorks 画 LIMIT** —— 上下两个极限值，各带符号。
`tolerance_type_readback: 2` 报的是"成功写入 LIMIT"，回执看不出异常。

**修法**：按真实枚举重排。断言**用值比，不用表比** —— 通过表取期望值的话，表错了测试也会跟着错。

### ② `before` 恒空（#7）

```python
before = note.GetText          # 绑定的方法对象
... isinstance(before, str) ... # False → ""
```

**每一张图、每一个格子，`before` 都是 `""`。** 所有"这格是不是空的"判断都建立在一个不可能非空的值上。

**修法**：`if callable(_raw): _raw = _raw()`。

### ③ 圆边字段从未填充（#8）

```python
if "model_start" not in item:    # ← 起点顶点解析成功就整段跳过
```

`sheet_point_on_circle` 是 0.8.98 专为"圆边该点哪里"加的，**但 145 条边里出现 0 次**。
所有依赖它的路径都在静默退回圆心。

**修法**：判据从"顶点是否幸运解析"改成"字段是否已填"。

### ④ 孔标注开关开着，视图里没有孔（#12）

```python
views = views or ["front", "right"]
```

右视图是端面 —— 7 条圆边全被拒。**孔在俯视图上，而俯视图从未创建**。
`defaults.hole_callouts: true`，`callouts.created: 0`，13 步全 ok，零警告。

**修法**：视图按类别给（轴类的俯视图是第二根长条，冗余）。

## 三、一条明确做不到的（#10）

折弯引线的水平段横穿公差值格。反馈建议「检测折线与框格 bbox 相交时给 warning」。

**检测建不起来**：

1. `SetLeader3` 只接受 style 和 side，拐点由 SolidWorks 算
2. `IGtol.GetLeaderAtIndex2` 不存在，读不回折线坐标
3. DXF 里引线是 362 条无归属 LINE 之一，定位不到哪条属于该标注

**做了**：`leader_path_note` 在选样式时说明局限，并点出唯一杠杆（换 `leader_side`）。

**原则**：**一个工具在自己从未检查过的路径上返回 `warning: null`，是在做一个它支撑不起的断言。**

## 五、我自己的三次退步（记下来）

**① 0.8.144 一跑就崩**

```python
"derived_unfilled": [d for d in keep_dimensions ...]
TypeError: 'int' object is not iterable
```

`keep_dimensions` 是**数量**，列表叫 `keep_list`。**158 条断言全过，照样上线** ——
断言只查字符串在不在源码里，**不查运行时能不能跑**。

**② 0.8.149 把 title block 改坏了两次**

`note.GetName` / `note.GetPosition` 当方法调用 → `'str' object is not callable`。
**从"能跑但写错格"变成"直接不可用"，是退步。** 回退确认 `ok: True` 后，
把诊断包进 `try` —— **诊断不能有能力弄坏写入**。

**③ `STATIC_REGRESSIONS = [` 忘加回四次**

每次都是 `Edit` 的 `old_string` 正好是那行、`new_string` 忘了带上。
