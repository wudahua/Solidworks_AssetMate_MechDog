## 一、三个 FAIL

### 1. `create_drawing scale=1:1 / save=False` —— 我的用例写错了

```
scale1:1 crashed: 'SolidWorks could not open the document...
  OpenDoc6 returned null with errors=65536 for doc_type=1 (.sldprt)'
```

**`errors=65536` 的注释说「文档类型不匹配」，实际是：同名文档已经开着。**

我的用例用**固定文件名** `smoke_path_scale11.SLDPRT`，而上一轮 smoke 被中断时
那个文档还留在会话里。SolidWorks 拒绝打开第二个同名文档，报的是一条误导性的消息。

**已修**：文件名加 `uuid4().hex[:6]` 后缀。

### 2. `edit tools by name (move/delete/layout)` —— 没有尺寸可编辑

### 3. `list_drawing_annotations with hole callouts` —— 创建 0 个

## 三、我这次的误操作（必须记下）

清理脚本用了：

```python
if (p and tmp in p.lower()) or p == '':
    sw.CloseDoc(title)
```

**`p == ''` 是错的。** 空路径不只是工具泄漏的空白图纸，**用户的未保存新文档也是空路径**。

那次关了 13 个，**无法确认里面有没有用户文件**。正确判据只能是：

| 判据 | 为什么安全 |
|---|---|
| 路径在临时目录下 | 工具自己创建的 |
| 标题匹配 `工程图\d+ -` **且**路径为空 | 泄漏的空白图纸有这个前缀 |
