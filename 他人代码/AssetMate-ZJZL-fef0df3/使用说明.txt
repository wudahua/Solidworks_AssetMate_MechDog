AssetMate ZJZL 能力增量包

适用基线为 AssetMate v0.8.351，Git 提交 fef0df3。
包内含五项能力的 15 个改动文件、验收说明和一个 Git 补丁。

解压后，在基线版本的 AssetMate 仓库目录中检查补丁。
git apply --check "<解压目录>\AssetMate-ZJZL.patch"

检查通过后，将补丁写入本地工作区。
git apply "<解压目录>\AssetMate-ZJZL.patch"

files/ 保留仓库相对路径，便于查看源码及对照手动合并。已包含同一批改动的工作区可直接查看 files/。
测试可运行 .\.venv\Scripts\python.exe -X utf8 -B tests\check_all.py。
真机验证说明见 files/docs/zjzl-capabilities.md，当前验证状态见 ZJZL-本地交付清单.txt。
安装或更新后，重启现有 AssetMate MCP 会话以加载六个 ZJZL 工具。
