## BOM 纯 Python 失败报告复核（11:47）
- 用户已验证 SelectByRay 11 参成功（True，选中 2 个），但五组 BOM 插入全 None。报告声称“严格按宏”，实际代码有至少四处不等价：

  2. `AnchorType=0`，宏为 `swBOMConfigurationAnchor_TopLeft=1`。
  3. `BomType=1`，官方 VBA 示例为 `PartsOnly=1`、`TopLevelOnly=2`、`Indented=3`；宏用 TopLevelOnly 应为 2。
  4. `IView` 官方 Remarks：**TopLevelOnly 时不要指定 Configuration**，应用 `''` 并通过 BomFeature 管理配置；这与模型侧 Extension 必须指定配置的规则相反。
- `doc.Extension.InsertBomTable4` 官方只用于零件/装配文档，当前是 SLDDRW，继续测没有诊断价值。
- “VBA 是早绑定”也错误：宏 `Dim swApp As Object`、`swModel` 未显式声明 ModelDoc2，是晚绑定；接口矛盾不应阻塞最小修正实验。
