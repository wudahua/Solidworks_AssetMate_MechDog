## 焊接符号复核
- 问题真实：交接图仅引线和数字，无 FILL 三角。
- 本机复核 `FILL`、`<WELD-FILL>`、官方 `BUTT` 示例、`SPOT`，均只写文本不生成图形；`SetProcess` 无效。`gtol.sym` 存在且 FILL 三 LINE 定义完整，`swDisplayWeldSymbols=True`，标准=GB(7)。
- 注意：FILL 是 LINE 组合，`GetTriangleCount=0` 不能单独判定缺失，必须 PDF 验证。
- 正确符号写法：SetText 用 `FILL`；旧 `IDrawingDoc.InsertWeldSymbol` 用 `<WELD-FILL>`（不是 ISO-FILL 或 WELD-FILLET）。但这些在当前环境仍未生成图形，不能宣称原生修复。
- 建议：交付优先用原生草图/块生成参考线+三角+尺寸，标 `representation="sketch_block"` 并 PDF 验收；原生 IWeldSymbol 需 UI 宏录制、早绑定/C#、SW2026 对照。
- 已产出《焊接符号_真实性复核与块级交付解决方案_20261103.md》。

## 形位公差引线最终解决
- 交接 `SetLeader3(1,True,2,0,True,True)` 参数解释错误；官方签名是 `(LeaderStyle, LeaderSide, SmartArrowHeadStyle, Perpendicular, AllAround, Dashed)`。返回 -2 = LeaderSide invalid，不是成功。
- 枚举：BENT=2，RIGHT=2；正确 `SetLeader3(2,2,True,True,False,False)`。
- 本机在真实图纸选中目标边后调用，返回 0、LeaderCount=1，PDF 实际显示转折引线。
- SetLeader3 只设样式，不负责附着；需先选边/面或创建时附着。验收须 status=0 + PDF 可见。
- 已产出《形位公差引线_参数纠错与已验证解决方案_20261103.md》。
