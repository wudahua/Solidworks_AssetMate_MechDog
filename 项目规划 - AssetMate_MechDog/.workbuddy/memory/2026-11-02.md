## P0 剖视无剖面线复核
- 用户提供 `P0-剖视无剖面线-交接.zip`，axis/door 两个零件剖视均只有轮廓无 hatch。问题真实。
- 本机实测：`call_method(view,'GetSection')` 可拿 DrSection，需再 `win.Dispatch`；`GetAutoHatch=False`、`ScaleHatchPattern=False`、`SectionDepth=0.00635`。
- 系统 `swDrawingAreaHatchFillStyle=2(Pattern)`、pattern ANSI31；零件 material style=2、pattern ANSI32；sldwks.ptn 存在。中间位置新建 B-B 仍无 hatch。
- 关键边界：`ScaleHatchPattern` 只是缩放已有图案，不是开关；`SetAutoHatch` 官方只对装配有效，零件无效；options=32 是 DisplaySurfaceCut，不是 hatch。
- 当前根因未唯一确定，优先视图级材质剖面线/颜色/图层与有效实体剖切几何；需 UI 对照 + 宏录制，交付前加 PDF hatch_missing 验证。
- 已产出《P0剖视无剖面线_真实性复核与解决方案_20261102.md》。

## GD&T 符号渲染实机突破
- 新建 GTol `GetFormat=1`，`GetFrame(1)=None`；`ConvertFormat` 后 `GetFormat=2` 但 `GetFrameCount=0`，必须 `AddFrame` 才能拿到 IGtolFrame。
- 本机 XSD 第 325 行要求 ToleranceSymbol 不含尖括号：正确 `IGTOL-POSI`；`<IGTOL-POSI>` 或 `&lt;IGTOL-POSI&gt;` 均 SetSymbolXml=False。
- 完整 XML 设置位置度后，PDF 实际显示 **⌖ 与基准 A**，证明 B 路径可用，不需 Unicode 替代。
- 剩余：`PrimaryToleranceValue=0.05` 已写入 XML，但 PDF 仍未显示数值；不能宣称完整框格成功。交付需分别检查 symbol/value/datum，错误码 gtol_symbol_missing/value_missing/datum_missing。
- 已产出《GD&T符号渲染_复核与IGtolFrame解决方案_20261102.md》。
