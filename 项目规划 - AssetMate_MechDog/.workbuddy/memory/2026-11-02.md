## P0 剖视无剖面线复核
- 用户提供 `P0-剖视无剖面线-交接.zip`，axis/door 两个零件剖视均只有轮廓无 hatch。问题真实。
- 本机实测：`call_method(view,'GetSection')` 可拿 DrSection，需再 `win.Dispatch`；`GetAutoHatch=False`、`ScaleHatchPattern=False`、`SectionDepth=0.00635`。
- 系统 `swDrawingAreaHatchFillStyle=2(Pattern)`、pattern ANSI31；零件 material style=2、pattern ANSI32；sldwks.ptn 存在。中间位置新建 B-B 仍无 hatch。
- 关键边界：`ScaleHatchPattern` 只是缩放已有图案，不是开关；`SetAutoHatch` 官方只对装配有效，零件无效；options=32 是 DisplaySurfaceCut，不是 hatch。
- 当前根因未唯一确定，优先视图级材质剖面线/颜色/图层与有效实体剖切几何；需 UI 对照 + 宏录制，交付前加 PDF hatch_missing 验证。
