# 给实现 AI 的任务说明

请按本包实施 AssetMate 工程图性能优化，不要重写整个出图系统。

## 必读顺序

1. `AssetMate_工程图性能优化_实施规格_20261103.md`
2. `验收矩阵.md`
3. `code/drawing_batch.py`
4. `code/perf_recorder.py`

## 工作方式

1. 先阅读当前源码，确认函数与规格中的名称仍存在；行号不是稳定契约。
2. 只做 PR0：性能采集与基线。不改行为。
3. 运行基线并提交 JSONL 结果，再进入 PR1。
4. 按 PR1→PR4 顺序实施；PR5 的 C# Shim 默认不做。
5. 每个 PR 单独提交，并附：改动文件、性能对比、正确性测试、未解决问题。
6. 不把“预期收益”写成实测结果。

## 硬性禁止

- 不使用不存在的 `swAutomaticRebuild`。
- 不把 `swDocumentTypes_e.swDocDRAWING` 当作用户首选项的第二参数。
- 不把 `AddDimension2` 写成带几何和尺寸类型的五参函数。
- 不用 `SetPosition` 假装改派尺寸所属视图。
- 不全局关闭图形更新来跑选择型尺寸 API。
- 不删除最终保存、审计和 PDF 正确性验证来换取速度。
- 不改变 GTol 已验证的旧格式写入→ConvertFormat→XML 顺序。
- 不用 C# `new SldWorks()` 连接另一实例。
- 不关闭用户文档，不覆盖未验证的正式交付文件。

## 完成定义

- 验收矩阵全部通过；
- 基线与优化后的中位数/P95 有真实样本数据；
- 首选项与文档数在异常后仍恢复；
- 无功能回退；
- 发布说明只引用实际测量结果。
