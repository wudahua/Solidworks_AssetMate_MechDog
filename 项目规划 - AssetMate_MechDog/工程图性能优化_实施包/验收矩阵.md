# 验收矩阵

## A. 行为不变

- [ ] 同一模型生成相同视图类型与数量。
- [ ] 比例仍使用标准比例，最终轮廓不越界。
- [ ] 模型尺寸覆盖不减少；等轴测空视图不误报。
- [ ] 同值但不同语义的尺寸不被误删。
- [ ] 技术要求、GTol、基准、粗糙度、BOM 均不丢项。
- [ ] GTol 的符号、数值、基准、引线均在 PDF 可见。
- [ ] BOM 数量列与数据行有效。
- [ ] 剖视剖面线与焊接图形的既有验证不被绕过。

## B. 异常与状态恢复

- [ ] 在尺寸创建、布局、注释、保存各阶段分别注入异常。
- [ ] 异常后 `swInputDimValOnCreate` 恢复。
- [ ] 异常后自动视图更新设置恢复。
- [ ] 异常后图形更新设置恢复。
- [ ] 不关闭用户已有文档。
- [ ] 本次创建的临时文档按归属清理。
- [ ] 正式文件不被半成品覆盖。

## C. 幂等与文档管理

- [ ] 同一输出连续运行两次，不重复插入对象。
- [ ] 第二次运行不重复移动用户已有尺寸。
- [ ] 打开文档数量在运行结束后回到基线。
- [ ] 输出路径被其他打开文档占用时明确失败。
- [ ] 保存后文件 mtime/大小证明真实写入。

## D. 性能

- [ ] baseline 与每个 variant 使用同一模型和模板。
- [ ] 每组记录至少 5 次，正式报告建议 10 次。
- [ ] 冷启动与热缓存分开。
- [ ] 输出中位数、P95、样本数和失败数。
- [ ] P95 不排除慢样本。
- [ ] 记录 ForceRebuild3、GraphicsRedraw2、保存、审计次数。
- [ ] 正确性未通过的样本不能作为性能成功样本。
- [ ] 只有实测收益才进入发布说明，不写未经验证的倍数。
