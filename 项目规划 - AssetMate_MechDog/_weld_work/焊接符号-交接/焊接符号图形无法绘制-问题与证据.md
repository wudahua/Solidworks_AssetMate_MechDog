# 焊接符号：图形画不出来（交接给规划者）

> 目标：让 `add_weld_symbol` 能画出焊缝图形（角焊三角、对接坡口、点焊圆等），
> 而不是只出一个引线加数字。
>
> 实测环境：SOLIDWORKS 2024 SP4（32.4.0）· Python 3.13 + pywin32 · 2026-11-03
> 证据：`证据/气缸盖_只有引线和数字6_无三角.png`、`证据/飞达动力轴_FILL_无三角.png`

---

## 一、现象

能插进去，能写文字，**但焊缝类型那个图形怎么都不出来**。

渲染结果（两个零件都一样）：

```
引线 ────────┬──────── 6
             │
        （水平参考线，线上应有角焊三角形，实际空白）
```

`GetTriangleCount` **恒为 0**。

---

## 二、能做出来的部分

```python
ws = Win.Dispatch(call_method(doc, "InsertWeldSymbol3"))   # 必须无参
ok = ws.SetText(True, "", "FILL", "6", "", 0)              # → True
```

- 引线：自动指向选中的边
- 水平参考线：自动
- 数字 `6`：写进去了，`GetText(3)` 读回 `'6'`
- 位置：`GetAnnotation().SetPosition(x, y, 0)` 可控

**位置和文字是好的，坏的只有图形。**

---

## 三、卡点一：`InsertWeldSymbol3` 只能无参

| 调用 | 结果 |
|---|---|
| `doc.InsertWeldSymbol3()`（属性派发） | `DISP_E_MEMBERNOTFOUND`「找不到成员」 |
| `call_method(doc, "InsertWeldSymbol3")` **无参** | ✅ 返回 `IWeldSymbol` |
| `call_method(doc, "InsertWeldSymbol3", "")` × 1~6 个空串 | ❌ 全部「找不到成员」 |

**不是 arity 猜错**——1 到 6 个参数全试过，无一成功；只有无参能过。

所以符号只能靠 `SetText` 事后设，**插入时不带任何焊缝类型信息**。

---

## 四、卡点二：`SetText` 的符号名只存文本，不渲染

### 官方签名

```
IWeldSymbol.SetText(Top, Left, Symbol, Right, Stagger, Contour)
```

### 官方支持的符号名（`gtol.sym`）

```
BUTT  BUSQ  BUSV  BUSB  BUSVBR  BUSBR  BUSU  BUSJ
BACK  FILL  PLUG  SPOT  SEAM  SEAMC  JSPT  JSM
```

**注意：表里没有 `FILLET`。** 角焊在 ISO 里是 fillet，但 SW 这张表没列它。

### 实测

| `Symbol` 传入 | `SetText` 返回 | `GetText(2)` 读回 | `GetTriangleCount` | `GetLineCount` |
|---|---|---|---|---|
| `"FILL"` | `True` | `'FILL'` | **0** | 3 |
| `"FILLET"` | `True` | `'FILLET'` | **0** | 3 |
| `""`（空） | `True` | `''` | **0** | 3 |
| `"<WELD-FILLET>"` | `True` | `'<WELD-FILLET>'` | **0** | 3 |

**`SetText` 全部返回 True，`GetText` 全部原样读回，但三角一个都没有。**

`GetLineCount = 3` 的构成：引线 + 水平线 + 一小段（可能是箭头）。**不含三角斜边。**

---

## 五、卡点三：`IWeldSymbol` 没有任何「指定图形」的方法

2026 版官方接口表（`IWeldSymbol Interface Members`）的方法全集：

| 方法 | 用途 |
|---|---|
| `GetText` / `SetText` | **读写文字与符号格（就是上面那条，只存文本）** |
| `GetFieldWeld` / `SetFieldWeld` | 现场焊/工地焊标志 |
| `GetProcess` / `SetProcess` | 焊接方法代号（如 111、135） |
| `GetProcessReference` | 方法代号是否带参考框 |
| `GetPeripheral` / `SetPeripheral` | 周边焊 |
| `GetStagger` / `SetStagger` | 交错焊 |
| `GetSymmetric` / `SetSymmetric` | 对称焊 |
| `GetContour` | **轮廓（只读！没有 SetContour）** |
| `GetAnnotation` | 拿 `IAnnotation`（位置、名称） |
| `GetTextCount` / `GetTextAtIndex` / `GetTextHeightAtIndex` / … | 只读几何 |
| `GetLineCount` / `GetLineAtIndex` / `GetArcCount` / `GetTriangleCount` / `GetArrowHeadCount` / … | 只读几何 |

**没有一个方法能指定「这个符号是角焊还是对接」。**
唯一带 `Contour` 的是**只读** `GetContour`。

---

## 六、和 GTol 的对比：同一个病，GTol 有解，焊接符号还没有

| | GTol 符号格 | 焊接符号格 |
|---|---|---|
| 症状 | `SetFrameSymbols2` 存中文、回读一致、图面空白 | `SetText` 存 `FILL`、回读一致、图面空白 |
| `GetTriangleCount` | 0 | 0 |
| 解法 | ✅ **`IGtolFrame` XML（2022+ 新架构）**：`ConvertFormat → AddFrame → SetSymbolXml` | ❌ **没有等价接口** |
| 关键 | 2022 换了一套帧对象 | `IWeldSymbol` 还是老架构 |

**GTol 那条路的三个前提，焊接符号一个都不满足**：

| GTol 有 | 焊接符号有吗 |
|---|---|
| `GetFormat` / `ConvertFormat`（新旧格式切换） | **无** |
| `AddFrame` / `GetFrame(n)` → `IGtolFrame` | **无** |
| `IGtolFrame.SetSymbolXml`（XML 描述帧） | **无** |

`IWeldSymbol` 的方法表里没有任何 XML 入口，也没有 frame 概念。

## 七、四条待试方向（按性价比排序）

### ① 旧接口 `InsertWeldSymbol2` / `InsertWeldSymbol`

`InsertWeldSymbol3` 是第三版。前两版的**参数表可能不同**——
如果旧版接受「焊缝类型」作为入参，那插入时就定了类型，不需要 `SetText`。

```python
for name in ("InsertWeldSymbol2", "InsertWeldSymbol"):
    try:
        for n in range(1, 8):
            try:
                raw = call_method(doc, name, *([""] * n))
                if raw is not None:
                    print(name, "arity", n, "OK"); break
            except Exception:
                continue
    except Exception:
        pass
```

**注意**：`InsertWeldSymbol`（第一版）在 2018 版文档里被列为 `IModelDoc2` 方法，
可能早绑定才能调——值得用 `gencache.EnsureModule` 再试一次（GTol 那轮验证过这条路可行）。

### ② `SetProcess` 会不会顺带把图形带出来

官方 `SetProcess` 的参数含「焊接方法代号 + 是否带参考框」。
**如果它同时触发符号重建**，可能会把 `SetText` 存进去的 `FILL` 真正实例化成图形。

```python
ws.SetText(True, "", "FILL", "6", "", 0)
ws.SetProcess(True, "135", True)      # 参数表待查
print(ws.GetTriangleCount)             # 会不会变 1？
```

**成本最低，建议先试这条。**

### ③ 文档属性里有没有「焊接符号默认样式」

`文档属性 → 注解 → 焊接符号` 是存在的（和基准点、形位公差同一族）。
如果那里有「按标准生成图形」的开关，可能是它关着。

**这一条和基准符号那次一样**——当时也以为是 API 问题，实际是文档属性。
**建议开宏录制，在 UI 里手工插一个角焊符号，看录到什么调用。**

### ④ 换 SW 版本对照

本机 32.4.0。反馈方机器是 SW2026（34.0.0）。
**如果 2026 上能画出来，这就是 2024 的缺陷**，只需写文档说明。

## 八、复现脚本

```python
import sys, os, shutil, tempfile
sys.path.insert(0, "src")
import win32com.client as win
from solidworks_assetmate_mechdog.tools import drawing

SRC = "测试用例/气缸盖/气缸盖.SLDPRT"
work = tempfile.mkdtemp(prefix="weld_")
part = os.path.join(work, "m.SLDPRT"); drw = os.path.join(work, "d.SLDDRW")
shutil.copy2(SRC, part)

try:
    drawing.create_drawing(part, output_path=drw, views=["front"], paper="A3")
    doc = drawing._open_drawing(drw)

    view = [v for v in drawing._iter_views(doc) if getattr(v, "Type", None) != 1][0]
    doc.ActivateView(view.Name)
    for comp in (view.GetVisibleComponents or ()):
        for e in (view.GetVisibleEntities2(comp, 1) or ()):
            win.Dispatch(e).Select2(False, 0)
            break
        break

    ws = win.Dispatch(drawing._invoke_as_method(doc, "InsertWeldSymbol3"))
    print("SetText:", drawing._invoke_as_method(ws, "SetText", True, "", "FILL", "6", "", 0))
    print("GetText(2):", drawing._invoke_as_method(ws, "GetText", 2))      # 'FILL'
    print("GetText(3):", drawing._invoke_as_method(ws, "GetText", 3))      # '6'
    print("triangles :", ws.GetTriangleCount)                              # 0  ← 问题
    print("lines     :", ws.GetLineCount)                                  # 3

    ann = win.Dispatch(drawing._invoke_as_method(ws, "GetAnnotation"))
    drawing._invoke_as_method(ann, "SetPosition", 0.10, 0.10, 0.0)
    doc.GraphicsRedraw2()

    pdf = os.path.join(work, "out.pdf")
    if drawing.export_drawing(drw, pdf).get("ok"):
        drawing.render_drawing(pdf, output_dir=work, scale=4.0)
    print("WORKDIR:", work)
finally:
    drawing.close_document(drw); drawing.close_document(part)
```

**预期输出**：`SetText: True`、`GetText(2): FILL`、`triangles: 0`，渲染只有引线和数字。

## 九、为什么这一版没发工具

`capabilities` 里已标 `weld_symbol: unsupported`，`com-quirks` 第五十三节有完整记录。

**一个只有引线和数字、没有焊缝类型的焊接符号，在车间比没有更危险**——
工人会以为"这里标了焊缝"，实际不知道角焊还是对接、焊脚多大。

这和 `add_section_view` 那条「宁可报错也不让没剖面线的图混出去」是同一个原则：
**宁可没有，也不要给一个看起来有、实际信息缺失的东西。**
