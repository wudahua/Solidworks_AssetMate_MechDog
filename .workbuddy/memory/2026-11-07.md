
## 2026-11-07 · 26 个版本（0.8.196 → 0.8.222），四份报告 P0 清零

### 起点
四份报告（v0.8.199 ×3、v0.8.215 ×1）共 30+ 条问题，其中 P0 八条。

### 关键突破：三个「我说过做不到」全部推翻

| 我说过 | 实际 |
|---|---|
| `NewSheet4` 调不通（0.8.180–195） | 参数顺序错，`TemplateIn` 是第三个且 type=int |
| 视图轴向没 API（0.8.174–196） | `GetOrientationName` 一直都在 |

### 一个认知错误，漏了四处

`_iter_views(doc)` 是**文档级**读取器，不是页级：
1. `list_sheets` 两页报同一视图列表
2. `add_view_to_sheet` 数总量，数量「没变」也算成功
3. **空页检查用文档级视图 → 空页也 ok:true**（0.8.201 以为修好了，其实从没生效）
4. `drawing_audit` / `delivery_check` 用第 1 页的框判所有页

**修法**：`ISheet.GetViews` + `expected` 参数，当前页不对就抛 `_SheetNotActive`。

### 五处「改为 id 就对了」

| 名字 | 只在哪赋值 | 谁在别处读 |
|---|---|---|
| `_title_scale_synced` | `saved and scale != 1:1` | 最终 `result.update` |
| `_final_scale` | 同上 | 回执 `chosen_scale` |
| `blocker` | `if save and output_path:` | `if blocker:` 清理 |
| `ai_supplied` | 参数默认 `None` | `len(ai_supplied)` |
| `verdict` | 我的新分支被后面默认值覆盖 | — |

### 四处「同一个 GetText 读错」

`IAnnotation` 没有 `GetText`；方法在 `INote` 且**无参数**：
1. `_note_at` 找格子 → 找不到 → 新建
2. 主循环读 `before` → 回执空
3. 比例栏读 `text` 做 n:m 匹配 → `unmatched`
4. **主循环 `marker not in text` 判据 → 所有格子走 `created"** ← 这才是「两处 POM」的根因

### 学到的三条

1. **断言锁定错误的实现细节 = 给 bug 上保险**。`_raw_before = note.GetText` 这条断言
   从 0.8.149 起守护了一个永不工作的表达式，三个版本没人发现。
   → 断言要查**结果**（`_note_text(note)`、`INote(`），不查实现细节。
2. **断言通过 ≠ 功能对**。`no_hatch` 字符串在函数里出现过，但被下一行无条件覆盖。
   夹具一跑就露 —— **回转体这个形态原来根本没有夹具**。
3. **判据太紧会把正确答案拒掉**。0.8.201 把「只有 Ø 覆盖」判成 blocker、
   0.8.200 把「插入前没尺寸」判成「读取失败」，都是这一类。
