`add_center_marks` 报 `views_marked: 1` 而 `center_mark_count: 0` ——
`AutoInsertCenterMarks2` 对**没有孔/槽几何的视图**返回 True 并插入 0 个。
**已修**：只在 `per_view > 0` 时计入，回执保留 `api_returned_true` 做对照。

**替代路径全部堵死**（2026-11-08 实测）：
- `ISketchSegment` 32 个属性**没有** Style / Width / Color
- `SetLineStyle` / `GetLineStyle` 类型库里不存在
- 只有 `FrameLineStyle` / `LeaderLineStyle`（GTOL 框架/引线）
- 图纸视图 `GetSketchSegments` → `AttributeError`

**能力表已改**：原来那句「中心线可以自己画」是错的，改成「点划线样的回转轴线目前没有可靠入口，需要手工画」。

## 一个反复出现的形状：把 API 返回值当结果

今天至少六次同一模式：
`_title_scale_synced` / `verdict: ok` / `views_marked` / `tolerance_precision_applied` /
`style_used` / `closed_on_failure`。

**判据应该是「图面/文档变了没有」，不是「函数返回了什么」。**
新写的回执一律同时给「请求了什么」和「实际发生了什么」两个字段。

### `measure_layout` 的一个坑（第 N 次同类）

第一版写 `sheet_obj.GetViews` → `<unknown>.GetViews`。
**`GetViews` 在 `ISheet` 上，图纸 dispatcher 拿不到** —— 这正是 0.8.203 加
`_sheet_model_views` 要解决的事。复用它一次就对。

**规律**：凡是「图纸对象上的集合属性」，都要考虑是不是在 `ISheet` 上、需要类型化。

### 未知参数校验的做法（可复用）

```python
@mcp.tool()
@_reject_unknown_arguments     # 靠 functools.wraps 保 __wrapped__
def ...
```

`inspect.signature` 跟随 `__wrapped__`，所以 **inputSchema 一个字不变**，只有调用被拦。
**没有用 `mcp` 包的私有扩展点**（`_mcp_server` / 中间件 hook 都会随版本漂）。
