## v0.8.20：P2-9 / P2-10 / P2-11 三项收尾（版本只 +0.0.1）

用户点名三项：`add_detail_view` 创建后校验 edge count > 0 且 scale 被锁返回 error；
形位公差 `<MOD-*-PAR>` 未生效改第一格文字 fallback 或明确拒绝创建；表面粗糙度导出
PDF/DWG 后的像素可见性自检。起点 v0.8.19 已发布，v0.8.6 反馈复核剩 9 项部分解决。

### 修改

- **P2-9 `add_detail_view`**：原代码 `scale = float(target.ScaleDecimal)` **覆盖了调用方
  请求的比例**（请求 2:1 静默变父视图 1:2），且空视图返回 `ok:true` + 安静的
  `scale_locked` 标志。改为 `requested_scale = float(scale)` 永久保留请求值，
  `parent_scale = float(target.ScaleDecimal)` 只用于边界圈草图坐标换算
  `(paper - view.Position) / parent_scale` 与 `CreateDetailViewAt4` 的第 5/6 参。
  新增 `_view_edge_count(view)`：`GetVisibleComponents` + `GetVisibleEntities2(comp, 1)`
  数可见边（实测 door.SLDPRT：边界圈落在父视图 outline 内 edges=1，落在外 edges=0，
  0 就是真空白视图，不是 API 抖动）。新增 `_apply_detail_scale(doc, detail, scale)`：
  4 轮 `UseParentScale=False` + `ScaleDecimal` + 回读 + `GraphicsRedraw2`，失败再
  `SaveSilent` 提交一次重试（新局部视图在未提交前会吞掉比例写入）。`edge_count == 0`
  返回 `detail_empty`，比例仍被锁返回 `detail_scale_locked` error（不再 ok:true）；
  成功返回 `requested_scale` / `parent_scale` / `scale` / `edge_count`。
- **P2-10 `add_geometric_tolerance`**：`SetFrameSymbols2` 传 `<MOD-POS-PAR>` 这类格式码
  **不会**解析成 GD&T 几何符号，只会被当**字面文本**存进去（框格里直接显示
  `<MOD-POS-PAR>` 字符串）。`GTOL_SYMBOLS` 全部改为可读中文（`position: 位置度` 等 15 项）。
  `SetFrameSymbols2` 返回 None（成功失败都返回 None），所以写入后必须
  `GetFrameSymbols2(1)[0]` 回读比对；不等则 `_delete_gtol()` 删掉半成品框格并返回
  `gtol_symbol_not_applied`（带 `symbol_requested` / `symbol_readback` /
  `symbol_is_text=True` / `frame_removed`）。能力表从 `pilot` 改 `partial`，摘要写明
  「符号为文字」。
- **P2-11 `add_surface_finish`**：`InsertSurfaceFinishSymbol3`（14 参）**忽略传入的 x/y**，
  符号实际落在图纸原点 (0,0)——旧代码回显 `position_m=[x,y]` 是谎报。改为创建后
  `symbol.GetAnnotation.SetPosition(x, y, 0)` 修正并回读 `position_actual_m` /
  `position_applied`。新增 `_sf_render_page()`：把**当前内存图纸** `SaveAsSilent` 成 PDF
  再 `render_drawing` 成 PIL 灰度图；`_sf_visibility_check()`：图纸原点在左下、PNG 原点在
  左上，必须 `px = x/sheet_w*W` / `py = (1-y/sheet_h)*H` 翻转，±50 px 窗口
  `ImageChops.difference` 统计 `>25` 的像素，`changed >= 20` 判 `visible`。开关
  `verify_render`（PDF 像素自检）/ `verify_dwg`（DWG 只查文件非空，矢量无像素通道）；
  PIL / pypdfium2 缺失时 `visibility.checked=false` 诚实降级，不整体失败。
